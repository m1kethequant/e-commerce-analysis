# Data

В проекте используется датасет **Online Retail** — транзакционные данные британского интернет-магазина за период с **01.12.2010 по 09.12.2011**.

Исходный датасет содержит около **542 тыс. транзакций** и следующие поля:

* `InvoiceNo` — номер заказа;
* `StockCode` — артикул товара;
* `Description` — описание товара;
* `Quantity` — количество товара;
* `InvoiceDate` — дата и время заказа;
* `UnitPrice` — цена единицы товара;
* `CustomerID` — идентификатор клиента;
* `Country` — страна клиента.

Оригинальный файл `Online Retail.xlsx` не включён в GitHub-репозиторий. Его можно скачать с [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail).
